# Projet Vite & Gourmand

Application de gestion de traiteur développée dans le cadre de l'ECF.

## Installation
1. Cloner le dépôt : `git clone ...`
2. Importer le fichier dans `/database/structure.sql` dans votre base MySQL.
3. Configurer `config.php` avec vos accès base de données.

## Fonctionnalités
- Gestion des menus, réservations et avis.
- Architecture hybride SQL/NoSQL pour les statistiques.
- Gestion des rôles (Admin/Employé/Client).
